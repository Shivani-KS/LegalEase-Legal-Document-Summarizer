# ⚖️ LegalEase — AI Legal Document Summarizer

LegalEase is an AI-powered legal document summarization application built using Python and Streamlit.

The application allows users to upload lengthy legal documents in PDF format, extract the document content, and generate concise AI-powered summaries to make complex legal information easier to understand.

LegalEase uses a fine-tuned Pegasus Transformer model for abstractive text summarization. The trained model is hosted separately on Hugging Face.

---

## 🚀 Features

- 📄 Upload legal documents in PDF format
- 🔍 Extract text from uploaded documents
- 📑 Preview extracted document content
- 🤖 Generate AI-powered summaries
- 🧠 Uses a fine-tuned Pegasus Transformer model
- 🖥️ Interactive Streamlit web interface
- ☁️ Model hosted on Hugging Face
- 🔐 Secure API-key handling using Streamlit Secrets
- 📦 Reproducible environment using `requirements.txt`

---

## 🧠 AI Model

LegalEase uses a fine-tuned **Pegasus Transformer model** for abstractive text summarization.

The model is hosted on Hugging Face:

👉 **[LegalEase-Pegasus on Hugging Face](https://huggingface.co/Shivani0906/LegalEase-Pegasus)**

The model is hosted separately from the GitHub repository because the trained model files are large.

## ⚙️ Installation:

1. Clone the repository:
       https://github.com/Shivani-KS/LegalEase-Legal-Document-Summarizer.git

Navigate to the project directory:
    cd LegalEase-Legal-Document-Summarizer

2. Create a virtual environment:
      python -m venv venv

Activate the environment on Windows:
    venv\Scripts\activate

For macOS/Linux:
    source venv/bin/activate

3. Install dependencies:
      pip install -r requirements.txt

## 🔐 API Key Configuration
If the application uses a Gemini API key, create:
      .streamlit/secrets.toml

Add:
    GEMINI_API_KEY = "YOUR_API_KEY_HERE"
(Replace YOUR_API_KEY_HERE with your own API key.)
